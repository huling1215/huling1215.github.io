紐西蘭 3 座雪場

紐西蘭奧塔哥皇后鎮與瓦納卡

  1. 首頁 /
  2. 雪場 /
  3. 紐西蘭 /
  4. 紐西蘭奧塔哥皇后鎮與瓦納卡

紐西蘭南島奧塔哥地區囊括皇后鎮皇冠峰、卓越山以及瓦納卡卡德羅納與三錐山，每年6月中旬至10月上旬提供北半球盛夏反季滑雪，湖景開闊且集鎮餐飲自駕配套成熟。

奧塔哥雪場全部位於樹線以上的高山草甸帶，視野無遮擋俯瞰瓦卡蒂普湖與瓦納卡湖：卡德羅納寬緩碗狀坡與U型池公園兼具，三錐山偏重陡峭自由滑地形，皇冠峰與卓越山則距皇后鎮中心僅25至45分鐘車程。

行前常見問題

017至8月去紐西蘭反季滑雪住皇后鎮還是住瓦納卡湖畔？

喜歡湖濱熱鬧餐廳與夜滑選皇后鎮；偏愛清靜慢節奏並重點刷卡德羅納和三錐山選瓦納卡，兩鎮相距約1小時車程也可分段入住。

02紐西蘭雪場盤山砂石公路自駕需要帶防滑鏈嗎？

降雪或結冰日山路檢查點會強制要求隨車攜帶並按指示安裝合規防滑鏈，不習慣山路駕駛也可直接搭乘鎮中心每日往返雪場巴士。

03奧塔哥雪場哪些支援Ikon或Mountain Collective國際通票？

皇冠峰與卓越山（NZSki旗下）同時加入Ikon通票與Mountain Collective聯盟，行前核對當季包含天數即可在山腳窗口啟用。
